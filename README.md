# AI-Based Recipe Recommendation System

This project recommends recipes based on ingredient similarity using basic AI/ML techniques in Python.

## Features
- Ingredient-based recipe recommendation
- Uses TF-IDF and cosine similarity
- Simple user interface built with Streamlit

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Streamlit

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
